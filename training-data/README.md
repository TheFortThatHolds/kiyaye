# Training Data Samples

Demonstrations of AI training data translated into endangered and minority languages.

## Format

Each file contains five sectors:

1. **Synthetic Reasoning** — Math problems with chain-of-thought
2. **Code & Syntax** — Python with comments in target language
3. **Factuality** — Textbook-style technical content
4. **Dialogue** — Multi-turn chat with persona switching
5. **Creative** — Literary descriptive prose
