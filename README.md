# Kiyaye

**"To keep safe. To preserve."** *(Hausa)*

A framework for translating content across languages while preserving structural and conceptual integrity.

Extended for endangered language corpus generation.

---

## What It Does

Translates content — therapeutic, technical, literary — into other languages without losing what makes it work.

Generates training data for languages that don't have enough digital text for AI systems to learn from.

## For Language Communities

Use it if it helps. Ignore it if it doesn't.

**Generated content requires verification by native speakers.** This generates raw material. Speakers decide if it's correct.

Communities decide:
- Whether to use it
- What to use it for
- When to stop

---

## For Linguists

The samples demonstrate corpus generation across:
- Reasoning (math with chain-of-thought)
- Code (technical documentation)
- Facts (textbook content)
- Dialogue (multiple registers)
- Literature (creative prose)

All unverified. Verification is the work.
